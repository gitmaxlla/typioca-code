# Журнал изменений

## 1.2 — 20.11.2026

Исправление направления форка в требованиях.

### Изменено

- FR-9 больше не описывает историю результатов: это практика на коде —
  наборы для Rust, Swift, Go, Kotlin и Clojure и подсветка синтаксиса.
- US-9 переписан под практику на коде; вариант использования FR-9 добавлен
  на диаграмму вариантов использования.
- В README обновлена строка статуса FR-9.
- В паспорт проекта добавлен раздел «Планируемое развитие».

## 1.1 — 19.11.2026

Уточнение документа требований и паспорта проекта.

### Добавлено

- FR-10 и US-10: добавление своего набора слов через TOML.
- Роль администратора инсталляции: наборы слов для пользователей сервера.
- Вариант использования «Добавить набор слов» (FR-10) и стрелка на диаграмме
  контекста.
- `docs/00-project.md`: 9 пользовательских функций и примечание о стандартных
  командах Cobra `help` и `completion`.

### Изменено

- FR-7 описывает только управление наборами и раскладками; подключение своего
  списка вынесено в FR-10.

## 1.0 — 09.11.2026

Версия 1.0 документа требований (лабораторная работа № 2).

### Добавлено

  сценарии US-1…US-9 и модели системы.
- `docs/diagrams/`: исходники PlantUML и PNG для контекста, деятельности,
